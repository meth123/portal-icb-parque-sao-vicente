# ICB Conecta

Aplicação web full-stack experimental para aprendizado e portfólio profissional.

Tecnicamente, o projeto combina um site público com o ICB Conecta, a área interna de gestão institucional. Ele possui características de um mini CRM: autenticação individual, perfis, papéis, permissões e organização de dados relacionais em uma única aplicação.

Tecnologias principais: Next.js, React, TypeScript, Tailwind CSS, Supabase/PostgreSQL e Vercel.

## Refatoração visual 2026

A sequência de dez etapas visuais do ICB Conecta foi concluída com foco em clareza, uso recorrente pela liderança e adaptação para celular.

- Identidade própria baseada no tema de 2026, “Caminhando em Unidade”, aplicada ao acesso e à área interna.
- Navegação responsiva, início mais objetivo e tutorial dedicado para o preenchimento das Fichas.
- Ficha reorganizada em etapas, com entrada rápida de nomes, evangelismo mais claro e PDF padronizado.
- Painéis da célula, pastoral e administrativo revisados para destacar indicadores sem excesso de informação.
- Biblioteca de documentos e Estrutura Organizacional transformadas em áreas de consulta com filtros e busca.
- Polimento final de responsividade, acessibilidade, navegação por teclado, iPhone/Safari e performance visual.

As regras de negócio, permissões e isolamento dos dados foram preservados durante a refatoração.
